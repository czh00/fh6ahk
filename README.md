# Forza Horizon 6 (FH6) 自動化輔助腳本

⚠️最下面有注意事項一定要看⚠️

本腳本是基於 **AutoHotkey v2** 編寫的《極限競速：地平線 6》(Forza Horizon 6) 遊戲輔助工具。腳本提供多種日常自動化行程，配備精美的懸浮 UI，並支援 **Xbox 遊戲控制器（手把）** 與 **鍵盤熱鍵** 雙重控制，適合用於簡化遊戲中的機械式重複操作。

---

## 🚀 版本資訊
* **最新版本**: `1.0.0`
* **適用環境**: Windows 系統、AutoHotkey v2.0+、系統管理員權限（腳本啟動時會自動嘗試獲取管理員權限）

---

## 🎨 懸浮 UI 與圖示功能說明

當遊戲視窗處於活動狀態時，左上角會顯示精緻的橫向懸浮 UI：

| 圖示 | 對應行程名稱 | 鍵盤觸發熱鍵 | 遊戲手把觸發方式 | 行程執行中中斷方式 |
| :---: | :---: | :---: | :---: | :---: |
| **␛** | **送出 Esc (叫出選單)** | `Esc` | ── | ── |
| **🚗** | **買車行程** | `F5` | 快速雙擊 **X** 鍵 | 按一下鍵盤 `F5` 或手把 **X** 鍵 |
| **⚔** | **賺技能點行程** | `F6` | 快速雙擊 **LB** 鍵 | 按一下鍵盤 `F6` 或手把 **LB** 鍵 |
| **🎰** | **連點 Enter 行程** | `F7` | 長按 **X** 鍵 (3秒) | 按一下鍵盤 `F7` 或手把 **X** 鍵 |
| **⚡** | **點技能行程** | `F8` | 長按 **Y** 鍵 (3秒) | 按一下鍵盤 `F8` 或手把 **Y** 鍵 |
| **🏆** | **油門行程** | `F9` | 長按 **LB** 鍵 (3秒) | 按鍵盤 `F9` 或**長按**手把 **LB** 鍵 (3秒) |
| **⏏** | **安全門 (關閉腳本)** | `F10` | ── | ── |

### 💡 執行狀態 UI 特性
* **運行中簡化**：當任一自動化行程啟動後，UI 會**自動隱藏其餘的按鈕**，僅保留當前正在運行的行程圖示。
* **進度與時間顯示**：運行中會展開顯示**黃色進度條**，並顯示當前循環進度、預估剩餘時間（格式為 `hh:mm:ss`）與執行步驟。
* **行程結束復原**：行程順利完成或玩家手動中斷時，UI 會自動回復為完整的七顆橫排圖示。

## ⚙️ 參數設定功能說明

您可以直接編輯 `fh6.ahk` 頂部的 **`[全域自動化參數設定區]`** 來調整腳本行為：

### ⏱️ 自動化延遲參數
* **`LoadVehicleDelay`** (預設: `11`)
  * 等待車輛載入的時間（秒），可根據您硬體的讀取速度調整。
* **`LongPressDelay`** (預設: `3.0`)
  * 手把長按按鍵的判定時間（秒），需按住該時間才會觸發對應行程。
* **`WHoldDuration`** (預設: `60`)
  * 賺技能點行程中，每次自動按住 W 鍵（前進/油門）的持續時間（秒）。

### 🔄 循環次數設定
* **`LoopCountLimit`** (預設: `10`)
  * **點技能行程** (`⚡`) 的循環次數。
* **`NewSequenceLoopLimit`** (預設: `50`)
  * **賺技能點行程** (`⚔`) 的循環次數。
* **`BuyCarLoopLimit`** (預設: `23`)
  * **買車行程** (`🚗`) 的循環次數。

### 📊 進度條分格設定
* **`IsSimplifyDividers`** (預設: `true`)
  * 進度條是否啟用簡化刻度。
  * **啟用 (`true`)**：若行程總次數 $\ge 20$ 次，進度條只會在**每滿 10 次**的比例位置畫出分割線，避免小格子過多導致畫面雜亂；非 10 的倍數（如 23 次）也能正確按比例留空。
  * **停用 (`false`)**：每一格都會完整畫出分割線。

## 🛡️ 安全防護與不失焦設計

為了防止誤觸與干擾，腳本內建以下防護機制：
1. **安全啟動確認框 (2倍放大版)**：
   * 啟動任何行程前，會彈出 `560 × 240` 像素的大字體確認視窗，顯示功能名稱、預估執行時間與次數。
   * 此確認框支援鍵盤 `Enter`/`Esc` 攔截，或手把 `A` 鍵確認、`B` 鍵取消。
   * **不失焦機制**：不論使用滑鼠點擊確認框，或是用鍵盤手把，確認後焦點會立刻安全回到遊戲中，遊戲**完全不會因此暫停**。
   * 當 `IsSimplifyDividers := false` 或次數少於 20 時，確認框會自動切換為不精簡的純次數提示詞。
2. **自動暫停安全機制**：
   * 當玩家按 `Alt+Tab` 或因其他原因切換出遊戲視窗時，腳本會**立即自動停止**當前運行的行程並重置 UI，防止在背景亂送按鍵。
3. **強制緊急釋放 (L3 + R3)**：
   * 同時按下手把的 **L3** (左類比下壓) 與 **R3** (右類比下壓)，或是按鍵盤 `F10`，腳本會立刻無條件停止所有運行的行程，釋放所有被按住的鍵盤按鍵並關閉 UI。

## 📥 安裝與使用說明

1. 下載並安裝 [AutoHotkey v2](https://www.autohotkey.com/)。
2. 將 `fh6.ahk` 放至您的電腦中。
3. 按兩下執行 `fh6.ahk` 啟動腳本（腳本會自動以管理員權限啟動）。
4. 開啟《極限競速：地平線 6》遊戲，即可點擊 UI 圖示、按鍵盤熱鍵或手把按鍵來啟動所需功能。


## ⚠️ 各行程操作注意事項與流程說明

### 1. ⚔ 賺技能點行程
請依序進入遊戲中的以下位置：
1. **創意中心**
2. **建立並瀏覽賽事**
3. **進行賽事**
4. **搜尋**
5. **分享代碼** `362177064`（之後再次搜尋時，不需要重新輸入代碼，直接切換頁簽往右切換至「我的歷史紀錄」即可看到此賽事）。
6. 選擇 **單人**。
7. 選擇滿技能的 **SUBARU 22B 1998** 要注意不能改車改了跑太快飛太遠反而賺比較少。
8. 停在此畫面時，點擊懸浮 UI 的 **⚔** 圖示即可開始自動刷技能點。

### 4. 🎰 連點 Enter 行程
* 啟用後會開始自動高速連點 Enter 鍵。
* **⚠️ 重要安全守則**：請務必在遊戲畫面**已經停在轉盤畫面**後再行啟用，以免在其他畫面誤觸其他功能。

---

### 5. 🏆 油門行程
* 啟用後腳本會自動按住 W 鍵前進（踩油門）。
* **防斷點與防斷線機制**：
  * 每隔一分鐘會自動鬆開油門幾毫秒（因為在《地平線 6》中，踩住油門超過十分鐘會被遊戲判定無操作而不再獲取技能點）。
  * 每個整點會自動按兩次 Enter 鍵，用以自動清除遊戲中彈出的斷線提示訊息，避免斷線訊息使遊戲暫停中斷。
